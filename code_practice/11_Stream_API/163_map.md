# Java map() Practice — 10 Coding Questions and 5 Interview Q&As

[← Road Map lesson](../../Road%20Map/11_Stream_API/163_map.md)

These exercises follow the corresponding Road Map lesson, progressing from basic operations to composition, boundary cases, and safe execution. Each coding question includes a model solution, expected output, and concept explanation.

**Java version:** Java 8+. Short snippets are independent and belong inside `main()`; assume imports from `java.util.*`, `java.util.function.*`, and `java.util.stream.*`. Complete programs include their helper types and should be saved as `Main.java`. Run questions separately. Inputs are non-null unless explicitly handled, and arithmetic uses small values that do not overflow. For checked I/O, `main()` must declare `throws Exception` or handle the failure.

## Question 1 — Integer squares

**Task:** Map [1, 2, 3, 4] to squares.

```java
System.out.println(Stream.of(1, 2, 3, 4).map(n -> n * n).collect(Collectors.toList()));
```

**Output:**
```text
[1, 4, 9, 16]
```

**Concept:** map produces one transformed result per processed input.

## Question 2 — String lengths

**Task:** Map [Ada, Grace, Alan] to lengths using a method reference.

```java
System.out.println(Stream.of("Ada", "Grace", "Alan").map(String::length).collect(Collectors.toList()));
```

**Output:**
```text
[3, 5, 4]
```

**Concept:** A mapper can change String elements into Integer results.

## Question 3 — Normalized names

**Task:** Trim and uppercase [" ada ", " grace "] using Locale.ROOT.

```java
System.out.println(Stream.of(" ada ", " grace ")
        .map(String::trim)
        .map(s -> s.toUpperCase(Locale.ROOT))
        .collect(Collectors.toList()));
```

**Output:**
```text
[ADA, GRACE]
```

**Concept:** Separate maps make normalization stages clear.

## Question 4 — Trim and parse

**Task:** Convert valid numeric strings [" 10 ", "20", " 3 "] into integers and sum them.

```java
System.out.println(Stream.of(" 10 ", "20", " 3 ").map(String::trim).mapToInt(Integer::parseInt).sum());
```

**Output:**
```text
33
```

**Concept:** Parsing is a transformation with an explicit valid-input contract here.

## Question 5 — Primitive length sum

**Task:** Sum lengths of Ada and Grace using a primitive mapping.

```java
System.out.println(Stream.of("Ada", "Grace").mapToInt(String::length).sum());
```

**Output:**
```text
8
```

**Concept:** mapToInt avoids boxed integer result elements.

## Question 6 — Primitive-to-object mapping

**Task:** Turn integers 1 through 3 into Item labels.

```java
System.out.println(IntStream.rangeClosed(1, 3).mapToObj(n -> "Item " + n).collect(Collectors.toList()));
```

**Output:**
```text
[Item 1, Item 2, Item 3]
```

**Concept:** IntStream.mapToObj creates a reference-result stream.

## Question 7 — Null-to-zero policy

**Task:** Map ["Ada", null, ""] to lengths, representing missing text as zero.

```java
System.out.println(Arrays.asList("Ada", null, "").stream()
        .map(s -> s == null ? 0 : s.length())
        .collect(Collectors.toList()));
```

**Output:**
```text
[3, 0, 0]
```

**Concept:** This policy deliberately conflates missing and empty strings.

## Question 8 — Null mapping results remain

**Task:** Map odd integers to null and evens to their values for [1, 2, 3], then collect.

```java
System.out.println(Stream.of(1, 2, 3).map(n -> n % 2 == 0 ? n : null).collect(Collectors.toList()));
```

**Output:**
```text
[null, 2, null]
```

**Concept:** Stream map does not automatically discard null results.

## Question 9 — Extract an object property

**Task:** Extract names from Ada/IT/90 and Bob/HR/80 using Employee::getName.

```java
import java.util.*;
import java.util.function.*;
import java.util.stream.*;

public class Main {
    static class Employee {
        final String name, department;
        final int salary;
        Employee(String name, String department, int salary) {
            this.name = name;
            this.department = department;
            this.salary = salary;
        }
        String getName() { return name; }
        String getDepartment() { return department; }
        int getSalary() { return salary; }
    }
    public static void main(String[] args) throws Exception {
        List<Employee> employees = Arrays.asList(new Employee("Ada", "IT", 90), new Employee("Bob", "HR", 80));
        System.out.println(employees.stream().map(Employee::getName).collect(Collectors.toList()));
    }
}
```

**Output:**
```text
[Ada, Bob]
```

**Concept:** Property projection can hide unneeded object fields in output.

## Question 10 — Nested map results

**Task:** Split Java streams and Java functions into lists using map, preserving two nested lists.

```java
System.out.println(Stream.of("Java streams", "Java functions")
        .map(line -> Arrays.asList(line.split(" ")))
        .collect(Collectors.toList()));
```

**Output:**
```text
[[Java, streams], [Java, functions]]
```

**Concept:** map retains each mapper result as one element instead of flattening it.

## Interview Questions and Answers

### Interview Question 1 — How many results does map produce?

**Answer:** One mapper result per processed input; it does not itself select fewer elements.

### Interview Question 2 — What is the difference between map and mapToInt?

**Answer:** map produces reference-stream results; mapToInt produces an IntStream with primitive numeric operations.

### Interview Question 3 — Does mapping preserve the source objects?

**Answer:** Only if the mapper follows that policy. The API does not prevent mutation or guarantee deep copies.

### Interview Question 4 — What happens if Integer.parseInt fails inside map?

**Answer:** NumberFormatException propagates through traversal unless an explicit parsing policy handles it. Streams do not silently skip malformed values.

### Interview Question 5 — Does a mapper automatically copy nested mutable objects?

**Answer:** No. Ownership and copy depth are part of the mapping implementation's contract.
