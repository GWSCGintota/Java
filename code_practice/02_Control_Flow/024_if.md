# Java if Practice — 10 Coding Questions and 5 Interview Q&As

[← Road Map lesson](../../Road%20Map/02_Control_Flow/024_if.md)

These exercises follow [024. if](../../Road%20Map/02_Control_Flow/024_if.md). Each coding question includes a task, model solution, expected result, and concept explanation.

**Java version:** Java 8+. Run each question independently. Unless a complete class is shown, place statements inside `main()` and helper declarations at class scope. Assume imports from `java.util.*`, `java.util.function.*`, `java.util.stream.*`, `java.io.*`, `java.nio.file.*`, and `java.time.*` when used. Inputs are non-null unless explicitly tested.

## Question 1 — Age gate

**Task:** Print Adult only for an age at least 18.

```java
int age = 20;
if (age >= 18) { System.out.println("Adult"); }
```

**Expected result:**
```text
Adult
```

**Concept:** A true condition executes the controlled statement.

## Question 2 — False branch

**Task:** Show that a false if body is skipped.

```java
int age = 16;
if (age >= 18) { System.out.println("Adult"); }
System.out.println("Done");
```

**Expected result:**
```text
Done
```

**Concept:** Execution resumes after an if whose condition is false.

## Question 3 — Inclusive boundary

**Task:** Test the exact adult-age boundary.

```java
int age = 18;
if (age >= 18) { System.out.println("Eligible"); }
```

**Expected result:**
```text
Eligible
```

**Concept:** Boundary operators determine equality behavior.

## Question 4 — Multiple statements

**Task:** Guard both output statements with braces.

```java
boolean ready = true;
if (ready) { System.out.println("Start"); System.out.println("Run"); }
```

**Expected result:**
```text
Start
Run
```

**Concept:** A block groups all intended guarded statements.

## Question 5 — Null guard

**Task:** Print a string's length only when it is present.

```java
String text = "Java";
if (text != null) { System.out.println(text.length()); }
```

**Expected result:**
```text
4
```

**Concept:** Validate a reference before dereferencing it.

## Question 6 — Change state

**Task:** Apply a discount only for a member.

```java
int price = 100; boolean member = true;
if (member) { price -= 10; }
System.out.println(price);
```

**Expected result:**
```text
90
```

**Concept:** An if body can update existing local state.

## Question 7 — Compound condition

**Task:** Print Valid for a score within 0–100.

```java
int score = 70;
if (score >= 0 && score <= 100) { System.out.println("Valid"); }
```

**Expected result:**
```text
Valid
```

**Concept:** A compound boolean expression is still one if condition.

## Question 8 — Independent checks

**Task:** Classify a value independently as positive and even.

```java
int number = 4;
if (number > 0) { System.out.println("Positive"); }
if (number % 2 == 0) { System.out.println("Even"); }
```

**Expected result:**
```text
Positive
Even
```

**Concept:** Separate if statements can both execute.

## Question 9 — Avoid empty statement

**Task:** Correct a stray-semicolon bug so a false condition suppresses the message.

```java
boolean enabled = false;
if (enabled) { System.out.println("Enabled"); }
System.out.println("Checked");
```

**Expected result:**
```text
Checked
```

**Concept:** A semicolon immediately after if would create an empty controlled statement.

## Question 10 — Derived condition

**Task:** Compute a named condition before using it.

```java
int stock = 3, requested = 2;
boolean enoughStock = requested > 0 && requested <= stock;
if (enoughStock) { System.out.println("Accepted"); }
```

**Expected result:**
```text
Accepted
```

**Concept:** Named boolean values can clarify domain intent.

## Interview Questions and Answers

### Interview Question 1 — What type must an if condition have?

**Answer:** boolean, or Boolean subject to unboxing. A null Boolean throws when unboxed.

### Interview Question 2 — Does indentation determine the guarded body?

**Answer:** No. Java syntax and braces determine it. Use braces consistently to make intent clear.

### Interview Question 3 — What is the stray-semicolon if bug?

**Answer:** if (condition); controls an empty statement, leaving the following block unconditional.

### Interview Question 4 — Can two consecutive if statements both execute?

**Answer:** Yes. They are independent checks, unlike the mutually exclusive branches of one if/else chain.

### Interview Question 5 — What should an if boundary test cover?

**Answer:** Values below, equal to, and above the threshold, plus invalid inputs when the domain permits them.
