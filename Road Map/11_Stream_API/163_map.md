# 163. map()

[Coding practice →](../../code_practice/11_Stream_API/163_map.md)

**Section:** Stream API

**Level:** Beginner → Advanced

**Version:** Runnable examples use Java 8-compatible APIs. Later additions are labeled explicitly.

## Learning goals

- Transform values with Function and primitive mapper interfaces.
- Track input and result types through a pipeline.
- Distinguish map from filter and flatMap, including null behavior.

**Example conventions:** Short snippets are independent and belong inside a method. Assume `java.util.*`, `java.util.function.*`, and `java.util.stream.*` imports unless shown otherwise. Inputs are non-null unless a snippet handles null explicitly. Numeric examples use small values that do not overflow.

## 1. One result for each input

`<R> Stream<R> map(Function<? super T, ? extends R> mapper)` is a lazy intermediate operation. Each processed input produces one mapper result, which can have another type. Mapping does not remove elements.

```java
List<Integer> lengths = Arrays.asList("Ada", "Grace", "Alan").stream()
        .map(String::length).collect(Collectors.toList());
System.out.println(lengths); // [3, 5, 4]
List<String> labels = Stream.of(1, 2, 3)
        .map(n -> "Item " + n).collect(Collectors.toList());
System.out.println(labels); // [Item 1, Item 2, Item 3]
```

The mapper may be a lambda or a compatible method reference. Its input must accept the upstream element type, and its result determines the next stream type.

## 2. Composition and normalization

```java
Function<String, String> trim = String::trim;
Function<String, String> upper = s -> s.toUpperCase(Locale.ROOT);
List<String> names = Arrays.asList(" ada ", " grace ").stream()
        .map(trim.andThen(upper))
        .collect(Collectors.toList());
System.out.println(names); // [ADA, GRACE]
```

Separate maps can also express separate stages. Use `Locale.ROOT` when casing should not depend on the machine's default locale. Mapping objects to new summaries or DTOs can preserve the source objects; modifying them inside the mapper has a different ownership contract.

## 3. Primitive mapping

```java
int total = Stream.of("Ada", "Grace").mapToInt(String::length).sum();
System.out.println(total); // 8
List<String> items = IntStream.rangeClosed(1, 3)
        .mapToObj(n -> "Item " + n).collect(Collectors.toList());
System.out.println(items); // [Item 1, Item 2, Item 3]
```

`mapToInt`, `mapToLong`, and `mapToDouble` produce specialized streams. `IntStream.map` takes an `IntUnaryOperator` and stays primitive; `mapToObj` creates reference results. `boxed()` adapts primitive values to wrapper objects.

## 4. Nested results and nulls

```java
List<List<String>> nested = Stream.of("Java streams", "Java functions")
        .map(line -> Arrays.asList(line.split(" ")))
        .collect(Collectors.toList());
System.out.println(nested); // [[Java, streams], [Java, functions]]
List<Integer> safeLengths = Arrays.asList("Ada", null).stream()
        .map(text -> text == null ? 0 : text.length())
        .collect(Collectors.toList());
System.out.println(safeLengths); // [3, 0]
```

A nested result remains one element per input. Use `flatMap` to flatten streams of results. A mapper returning null creates a null stream element; `Optional.map`, by contrast, converts a null mapping result to an empty optional. Some downstream operations cannot accept null, so choose a null policy early.

## 5. Failures and effects

Parsing with `Integer::parseInt` can throw `NumberFormatException`. A stream does not automatically skip malformed values. Validate, return a richer result, or implement a deliberate failure policy.

Mappers should be stateless and non-interfering. Avoid using a map stage solely for required effects or depending on how many times it executes: terminal operations such as `count` may legally avoid transformations when their results are unnecessary. A mapper does not deep-copy nested mutable objects automatically.

## 6. Complete runnable example

Save as `StreamLesson163.java`.

```java
import java.util.*;
import java.util.function.*;
import java.util.stream.*;

public class StreamLesson163 {
    public static void main(String[] args) throws Exception {
        List<String> input = Arrays.asList(" ada ", " grace ");
        List<String> normalized = input.stream().map(String::trim)
                .map(text -> text.toUpperCase(Locale.ROOT))
                .collect(Collectors.toList());
        System.out.println(normalized);
        System.out.println(normalized.stream().mapToInt(String::length).sum());
        System.out.println(IntStream.rangeClosed(1, 3).mapToObj(n -> "Item " + n)
                .collect(Collectors.toList()));
        System.out.println(input);
    }
}
```

Compile and run:

```shell
javac StreamLesson163.java
java StreamLesson163
```

Expected output:

```text
[ADA, GRACE]
8
[Item 1, Item 2, Item 3]
[ ada ,  grace ]
```

## 7. Common mistakes

| Mistake | Better approach |
|---|---|
| Returning boolean from map to select elements | Use filter for selection. |
| Expecting map to flatten collections | Use flatMap with a stream-producing mapper. |
| Dereferencing a nullable mapper input | Guard it or define a fallback. |
| Ignoring mapper exceptions | Define an explicit failure strategy. |
| Using map only for required side effects | Use an action or explicit control flow. |

## 8. Practice exercises

1. Map integer values to squares. **Hint:** Use map for reference values or IntStream.map for primitives.
2. Convert numeric strings to integers after trimming. **Hint:** Compose trim with parsing and define invalid-input behavior.
3. Extract a property from custom objects. **Hint:** Map with a getter reference.
4. Sum string lengths without boxed integer results. **Hint:** mapToInt then sum.
5. Contrast map of a split result with flatMap. **Hint:** Inspect the resulting nested versus flat type.

## 9. Interview questions and answers

### 1. How many results does map produce?

One mapper result per processed input; it does not itself select fewer elements.

### 2. What is the difference between map and mapToInt?

map produces reference-stream results; mapToInt produces an IntStream with primitive numeric operations.

### 3. Does mapping preserve the source objects?

Only if the mapper follows that policy. The API does not prevent mutation or guarantee deep copies.
