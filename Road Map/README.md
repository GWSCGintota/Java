# Java Learning Roadmap — Beginner to Advanced

This course pack contains **580 numbered Java learning topics**. Each topic has its own Markdown file, ordered from beginner fundamentals to advanced Java/backend/software architecture.

## How to use this pack

1. Start at Topic 001 and progress in order.
2. Read the learning goal and key points.
3. Expand the starter snippet into working code.
4. Complete the practice task.
5. Tick the checklist before moving on.

> Note: Topic **377 — Repository Pattern** was added to fill the numbering gap in the original roadmap and because it was already included in the recommended design patterns.
