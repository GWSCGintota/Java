# 115. List

**Section:** Java Collections Framework  
**Level:** Beginner → Intermediate

##1. List Interface
 - The list interface is the child interface of the Collection interface. 
 - It can have duplicate values.
 - The list interface is implemented by the classes ArrayList, LinkedList, Vector, and Stack.
 - To instantiate the List interface, we must use:

```
List <data-type> list1= new ArrayList();  
List <data-type> list2 = new LinkedList();  
List <data-type> list3 = new Vector();  
List <data-type> list4 = new Stack();  

```
Various methods in List interface can be used to insert, delete, and access the elements from the list. The classes that implement the List interface are given below:

 - ArrayList
 - LinkedList
 - Vector
 - Stack
