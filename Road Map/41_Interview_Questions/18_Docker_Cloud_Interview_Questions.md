# Docker, Cloud & DevOps Interview Questions

Use these as revision prompts. Try answering each question aloud before opening the answer.

## 1. Image vs container?

**Answer guide:** An image is an immutable template; a container is a running instance of an image.

## 2. What is a Dockerfile?

**Answer guide:** A build recipe for creating a container image.

## 3. What is Docker Compose?

**Answer guide:** A tool for defining and running multi-container applications locally or in simple environments.

## 4. Why containerize a Spring Boot app?

**Answer guide:** For consistent packaging, isolation, portability, and predictable deployment.

## 5. What is CI/CD?

**Answer guide:** Automated integration, testing, packaging, and delivery/deployment workflows.

## 6. What is a load balancer?

**Answer guide:** A component that distributes traffic across multiple backend instances.

## 7. What is a reverse proxy?

**Answer guide:** A server that receives client requests and forwards them to backend services.

## 8. What is Kubernetes?

**Answer guide:** A platform for orchestrating containerized applications across clusters.

## 9. What is observability?

**Answer guide:** Understanding system behavior through signals such as metrics, logs, and traces.

## 10. Metrics vs logs vs traces?

**Answer guide:** Metrics quantify trends, logs record events, and traces follow requests across components.
