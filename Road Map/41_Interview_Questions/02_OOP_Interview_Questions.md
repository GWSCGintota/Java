# OOP Interview Questions

Use these as revision prompts. Try answering each question aloud before opening the answer.

## 1. What are the four pillars of OOP?

**Answer guide:** Encapsulation, inheritance, polymorphism, and abstraction.

## 2. What is encapsulation?

**Answer guide:** Keeping data and behavior together while controlling access to internal state.

## 3. What is inheritance?

**Answer guide:** A mechanism where a subclass reuses and specializes behavior from a superclass.

## 4. What is polymorphism?

**Answer guide:** One interface or reference type can represent multiple concrete implementations.

## 5. What is abstraction?

**Answer guide:** Exposing essential behavior while hiding unnecessary implementation details.

## 6. Method overloading vs overriding?

**Answer guide:** Overloading uses the same method name with different parameter lists; overriding replaces inherited behavior with the same compatible signature.

## 7. Can constructors be overridden?

**Answer guide:** No. Constructors are not inherited.

## 8. What is constructor chaining?

**Answer guide:** Calling another constructor using `this(...)` or a superclass constructor using `super(...)`.

## 9. Abstract class vs interface?

**Answer guide:** Abstract classes can hold state and constructors; interfaces mainly define contracts and can have default/static methods.

## 10. Can a class implement multiple interfaces?

**Answer guide:** Yes.

## 11. Can a class extend multiple classes?

**Answer guide:** No. Java does not support multiple class inheritance.

## 12. Composition vs inheritance?

**Answer guide:** Composition builds objects from other objects and is often more flexible; inheritance models an is-a relationship.

## 13. What is association?

**Answer guide:** A general relationship where one object knows or uses another.

## 14. What is aggregation?

**Answer guide:** A weak whole-part relationship where parts can exist independently.

## 15. What is composition?

**Answer guide:** A strong whole-part relationship where parts are usually owned by the whole.
