# Data Structures & Algorithms Interview Questions

Use these as revision prompts. Try answering each question aloud before opening the answer.

## 1. What is Big-O notation?

**Answer guide:** A way to describe how runtime or memory grows with input size.

## 2. Array access complexity?

**Answer guide:** O(1) by index.

## 3. Binary search complexity?

**Answer guide:** O(log n) on sorted random-access data.

## 4. Hash table average lookup complexity?

**Answer guide:** Typically O(1) average, with worse cases possible.

## 5. BFS vs DFS?

**Answer guide:** BFS explores by layers using a queue; DFS explores depth-first using recursion or a stack.

## 6. When is a stack useful?

**Answer guide:** LIFO problems such as parsing, backtracking, call simulation, and undo.

## 7. When is a queue useful?

**Answer guide:** FIFO workflows, BFS, buffering, and task processing.

## 8. What is a heap?

**Answer guide:** A tree-based structure that efficiently exposes the minimum or maximum element.

## 9. What is dynamic programming?

**Answer guide:** Solving overlapping subproblems once and reusing their results.

## 10. What is backtracking?

**Answer guide:** Exploring candidate choices recursively and abandoning invalid paths.

## 11. What is Dijkstra's algorithm used for?

**Answer guide:** Shortest paths from one source in graphs with non-negative edge weights.

## 12. What is recursion?

**Answer guide:** A function solving a problem by calling itself on smaller instances, with a base case.
