# Comprehensive Java Course

> **Baseline:** Java 25 LTS  
> **Current context:** Java 26 is the latest Java SE feature release.  
> **Purpose:** A modular Java learning guide with one Markdown file per topic.

---

## How to use this course

1. Start from Topic 1.
2. Open each linked topic file in order.
3. Run the code examples in an IDE or from the command line.
4. Complete the practice tasks at the end of each topic.
5. Use the final interview questions page for revision.
